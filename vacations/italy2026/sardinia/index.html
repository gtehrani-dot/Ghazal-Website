What's settled

Routing and flight logistics from prior research.

Routing

Multi-city (open-jaw): IAD → Milan → Sardinia → home via Rome. This avoids backtracking to Milan and saves a flight segment compared to a round-trip-from-Milan structure.

Getting there

Milan → Olbia is a short domestic hop (~1h20-1h45, easyJet/Neos/Wizz Air) — no passport control since Sardinia is part of Italy.

Getting home

Olbia/Cagliari → Rome Fiumicino → home. ITA Airways flies FCO–IAD as a genuine nonstop (~9 hrs), so it's one clean connection instead of two.

Return flight noted

Return leg discussed: OLB → LHR → BWI on British Airways, mid-August. Worth confirming this is still the booked routing given the ITA/Rome option above may be simpler.

Hotel front-runners

Two boutique options researched so far, both with direct water access.

Capo d'Orso Hotel Thalasso & SPA

Palau, Sardinia

Private cove with direct kayak access from the villas — dramatic granite coastline setting near the La Maddalena archipelago.

Is Morus Relais

Santa Margherita di Pula, Sardinia

Boutique beachfront property with kayak rentals right from shore — quieter, less glossy than Costa Smeralda proper.
